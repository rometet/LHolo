# Contributing to LHolo

Start with [the beginner guide](docs/START_HERE.md). Japanese and English contributions are welcome.

Base each focused branch on current main (or state an explicit PR dependency). Link an issue, describe acceptance criteria and checks, and use a draft for incomplete work. Never replace the current release with an older experiment. Keep source and tests together; avoid unrelated changes. Do not include credentials, personal information, proprietary files, worlds, binaries, logs or dumps. Preserve the project license and all third-party attribution. See [LICENSE](LICENSE) and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Build/unit test results are distinct from actual Minecraft runtime results.
