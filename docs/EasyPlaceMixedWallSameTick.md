# Easy Place: 混在素材の壁・同一Tickでの持ち替え（実験版）

対象: LHolo PR #41 / Bedrock 1.26.60.05 (client) + 専用BDS 1.26.63.1。

## 機能
- **縦の壁のみ。** 上段の投影を照準で指定して、そのX/Z列の下段から上へ最大4個/クライアントTickを試行する。
- 同じ列内で通常の不透明なフルブロックが異なる場合、ホットバー内の必要なスロットを探し、選択変更時に `MobEquipmentPacket` を先に送信し、その後 `GameMode::buildBlock` で設置する。同じTickで何回切り替えてもよい。順序の例: Stone -> Blackstone -> Stone -> Deepslate。
- スロットごとに開始個数/IDと送信数を管理し、足りない素材は二重消費しない。既存の設置予約ロックが重複を抑止。
- ホットバー外の素材は、既存のサーバー同期スワップで持ち込む。これは同一Tickで設置できない。最大9種類の手持ち素材に限り即時切り替えが可能。
- ステート/方向を持つ階段、ハーフブロック、接続ブロック、ドアなどは旧処理を維持。1Tickに4種類何でも置けると断言しない。床の2×2設置拡張は削除。

## 安全性と検証
- 同じバースト内でネイティブ設置と手製 `ItemUseInventoryTransaction` を混在させない。
- 向き依存・設置面がないブロック、範囲設置や手動設置は既存方式。
- オフラインソース抽出フィクスチャで混在素材の下から上への順序、装備通知と設置の送信順序、残数制限、旧方式への回帰を確認。
- **現時点では複数素材がBDSで同一Tickに受理されたことは未確認。** 以前の石のみ4個/Tick成功とは区別する。正式マージ前にBDSの `world.afterEvents.playerPlaceBlock` で各Tickの座標/種類/順序を測定する。
- ゲーム中のDLL交換はしない。試験データは別のBDSで扱い、旧DLLとconfigはバックアップ。
