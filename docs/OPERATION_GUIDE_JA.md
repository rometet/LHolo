# Praxis / LHolo 操作ガイド

通常pairの確認基準は Praxis `352f780d68dcf8b1b57d18dd3d0b9473abc4a469`、
LHolo `a35125c2a70e864545d4042ff01c7983cbeb82e2` です。
このガイドはソースで確認した操作を説明します。日本語化候補のゲーム実機確認は未実施です。
キーと初期状態は新規設定の場合です。保存済み設定がある場合は画面の現在値を優先してください。

## 最初に開く画面

- **F10**: Praxisを開く／閉じる。
- **Insert**: LHoloを開く／閉じる。LHoloのチャット入力でも開けます。
- LHoloが別の言語なら「インターフェース → 言語 → 日本語」を選びます。
- **F11**: Minecraftの全画面切替。Modへの割当には使いません。
- Praxisのカードは「入・切」で有効化。カード本体か設定アイコンで詳細、星でお気に入りです。
- 機能の効果やゲーム用キーを試す時は、Modメニューを閉じてゲームへ戻ります。

Praxisの15機能・情報HUD・満腹度HUD・オフハンドHUD・耐久値HUD・バンドルプレビュー・地図は初期OFFです。
ON/OFF用の機能キーも初期は未設定。ズーム操作はC、地図のON/OFFはMです。
LHoloの設計図HUDは初期ON、材料HUDは初期OFFです。

## 道具・武器・手持ち

| 画面の機能名 | 使い方 | 止める方法・制約 |
|---|---|---|
| 道具の破損防止 (ToolProtection) | ONにし、残り耐久値と耐久率の下限を設定。採掘前に下限を確認します。初期下限は残り1、割合0%、攻撃の保護もON。 | 下限になると停止。押し直しても解除されません。道具を交換するか機能をOFF。道具の使用操作や一度に複数の耐久値を使う操作は対象外です。 |
| 武器の自動選択 (WeaponSwitch) | ONにして攻撃するとホットバーの武器から選択。基礎攻撃力順／剣優先／斧優先／メイス優先を選べます。同じ優先度なら現在の武器、耐久値、若い番号の順です。 | OFFで停止。所持品の本体からは選びません。「攻撃後に戻す」は初期OFFで、サーバーでの処理順は未確認です。 |
| 手持ちの自動補充 (HandRestock) | ONにして物を使用。使用成功や食事・飲み物の完了を観測した後、選択中のメインハンドの残数が設定以下なら同じ予備を補充。初期残数6、待ち時間150ms。 | OFFや不明な内容変更で停止。オフハンドには補充しません。初期は所持品本体から補充し、他のホットバーは使いません。空のバケツ・瓶・ボウルの交換は設定で選べます。 |

これらはゲーム内の実機受入を残す試験機能です。UIの説明とソース上の条件を、実機成功の報告とは区別してください。

## 所持品を整理する

1. F10 →「機能一覧」→「所持品の整理」をON。
2. 詳細の「整理キー (番号)」にWindowsのキー番号を入力します。**Rなら82、Gなら71、0なら未設定**。
   入力欄の下に実際のキー名と番号を表示します。初期値は0なので、そのままでは実行できません。
3. F10を閉じ、インベントリまたは通常の収納画面を開きます。
4. 整理したい側の領域にカーソルを合わせて、指定したキーを押します。
   手持ち側なら手持ち、収納側なら収納を整理します。

「キー割当」画面の「所持品の整理」は**機能のON/OFF用**です。
上の整理実行キーとは別で、現在は数値入力です。整理実行用のBind画面や専用取消キーは実装していません。

種類・アイテムデータ順、同じ物は個数の多い順に並べます。
「同じスタックをまとめる」は初期ON。「ホットバーを保持」も初期ON。
「手持ちの除外」「収納の除外」でチェックした番号は動かしません。
手持ちの1〜9はホットバーです。装備・作業・出力・固定スロットは対象外。
画面を閉じる、機能をOFFにする、途中の内容変更や移動失敗で停止します。

## ホイール・ドラッグで移動する

1. F10 →「ホイール・ドラッグ移動」をONにし、F10を閉じます。
2. 通常の収納画面で、アイテムがあるスロットにカーソルを合わせます。
3. 次の操作で手持ちと収納の間を移動します。

| 操作 | 動作 |
|---|---|
| ホイール上 | 同じアイテムを収納へ1個 |
| ホイール下 | 同じアイテムを手持ちへ1個 |
| Shift + ホイール | 上と同じ方向にスタック単位 |
| Ctrl + 左ドラッグ | 通過した各スロットから反対側へ1個 |
| Shift + 左ドラッグ | 通過した各スロットから反対側へスタック単位 |

CtrlとShiftを同時に押したドラッグはCtrlを優先します。
一押し中、同じスロットは1回だけ処理し、左ボタンを離すとドラッグ終了。
「ホイール方向を反転」がONなら上下の方向は逆です。
初期はホットバーと整理の除外スロットを保持します。
空のスロットや移動できる同じアイテムがない場合は何も移動しません。
文字入力、カーソルにスタックを持った状態、画面終了、移動失敗時は停止します。

## 中身のプレビュー・HUD

| 表示 | 開く場所と操作 |
|---|---|
| シュルカーの中身 | 機能一覧でON。インベントリのシュルカーボックスにカーソルを合わせます。ホットバー表示、個数、スロット番号、倍率、背景色を詳細で選びます。OFFで非表示。 |
| バンドルの中身 | F10 →「HUD・バンドル」→ON。インベントリのバンドルにカーソルを合わせます。下のバンドル設定でホットバー表示、空きスロット、Shift限定、個数、番号、倍率を選びます。 |
| 情報HUD | 同じ画面でON。「情報の表示項目」で座標・方角・チャンクなどを選択。取得できない項目は通常は非表示で、「取得不可も表示」をONにするとその状態を表示します。FPSとフレーム時間はHUD側の値です。 |
| 装備の耐久値HUD | 同じ画面でON。手・装備の耐久値を表示。バー＋数値／数値／バーを選べます。無傷の装備の表示、位置を設定できます。 |
| 満腹度HUD | 同じ画面でON。満腹度と隠し満腹度は端末側の属性値。隠し満腹度は有効な属性値の変化を観測するまで「不明」。0は数値0.00です。初回の静止値を受信済みとは断定せず、消耗度は未確認のため「不明」です。食事・移動から推定していません。 |
| オフハンドHUD | 同じ画面でON。左手のスロット、個数、耐久値を表示。空スロットを表示するか、各項目と位置・倍率を選べます。自動補充の対象を増やす設定ではありません。 |

「不明」「取得不可」は0ではありません。
HUDをOFFにするとその表示を止めます。通常のHUD表示は入力を取りません。

## HUDを移動・保存する

F10 →「HUD配置」で、情報・装備・オフハンド・満腹度・チャンクの位置を編集します。
連携が使えるLHoloを読み込んでいる場合は、設計図・材料の2パネルも編集できます。

1. 「対象HUD」でパネルを選択。
2. プレビューを**左ドラッグ**して移動。
3. 「倍率」「基準位置」「横のずれ」「縦のずれ」で調整。
   基準位置は上・中央・下と左・中央・右の9通りです。
4. **「保存」で確定**します。

「初期化」「全体を初期化」は従来の配置へ戻す**下書き**です。適用するには保存が必要。
「読込み」は未保存の編集を取り消して現在値へ戻します。
プレビューの枠サイズは目安。LHoloの倍率は、現在のLHolo HUD倍率に掛け合わせます。
Praxisの配置は現在のconfigに含まれ、名前付きの保存設定へ残す場合は「保存設定」で保存します。
LHolo連携が未準備の場合は、Praxisの5パネルだけを編集できます。

## キーを割り当てる

F10 →「キー割当」はPraxisとLHoloをまとめて表示します。

- 「割当」→新しいキーを押す。Ctrl・Shift・Altも組合せ可能。
- 入力中のEsc、または「取消」→元の割当を保持して取消。
- 「解除」→未設定。「初期化」→その項目の既定値へ戻す。
- 検索で操作・Mod・使用場面を絞り込み。「重複だけ表示」で競合を確認。
- F10/F11は固定。地図の6操作は初期未設定で、修飾キーの有無を問わない従来の動作です。
- Praxisの機能キーはメニュー・チャットなどに入力を渡している間は動作しません。
  LHoloは元のゲーム操作／メニュー操作の使用場面を保持します。
- 設定変更は現在の設定へ保存されます。名前付きの保存設定を上書きする操作とは別です。

LHolo単独の「ホットキー」では、キー表示のボタンを押して入力します。
Escで取消、Delete／Backspaceか「解除」で未設定。「---」は未設定です。
移動・投影読込み・閉じる・手動設置切替はゲーム操作中に使います。
メニューと配置／ファイル／検証／材料の直接キーはModメニュー内でも使えます。
重複した直接キーは無効になるため、画面の重複表示を解消してください。
直接キー4つ、投影読込み・閉じる、手動設置切替は初期未設定です。

## 地図・地点

F10 →「地図」で設定します。初期OFF。ゲーム操作中に**M**で地図のON/OFF。
ミニマップ、円形、北を上に固定、洞窟、レーダー、座標、地点の印を選べます。
レーダーは現在プレイヤーが対象で、敵対・友好Mob・アイテム・その他は未対応です。
塗った上三角は高い位置、点は同じ高さ、枠の下三角は低い位置 (差4ブロック)。

「広域地図」を開くと、左ドラッグで移動、ホイールで拡大縮小。
「自分を中心に」で現在位置へ戻します。読込み済みの床で右クリックすると地点の下書きを作ります。
名前・座標・次元・色・表示を確認して**「地点を追加／保存」**を押します。
次元は0＝地上、1＝ネザー、2＝ジ・エンドです。
一覧の「中心へ」「編集」「削除」「表示」で各地点を操作します。
「編集」の変更も、下書きを保存するまで確定しません。
「地図を初期化」「設定を1つ戻す」は地図設定の操作です。
走査・読込みしていない地形は表示できず、読込みや保存の状態は画面に表示します。

## LHoloの設計図・配置・検証・材料

### ファイルを読み込む・配置を作る

ワールドに入り、Insert →「ファイル」。
「参照」で `.mcstructure` または `.litematic` を選び、「読み込む」。
保存フォルダーの一覧は「ファイル一覧を更新」。一覧の「足元に配置」で配置を作ります。
「保存済み投影を取り込む」は保存済み投影をライブラリーへ取り込む操作です。
Praxis側の「設計図」はLHoloへの案内で、そこから直接読込みはできません。

### 配置を選んで調整する

「配置」一覧から選ぶと、その配置が操作対象になります。
「足元へ移動」、座標、回転、反転、表示、レイヤーを設定します。
選択を解除するには「選択解除」。「配置を削除」は配置だけを削除し、元ファイルは残します。
Xは東西、Yは高さ、Zは南北。下の「変形」では数値と＋・－で調整できます。

- Ctrl＋左／右／上／下: プレイヤーから見た左右／前後。
- Shift＋上／下: 高さ。
- Alt＋上／下: 表示レイヤー。
- Alt＋ホイール: 投影を前後へ移動。キー割当画面でON/OFFできる固定操作です。

移動やレイヤーのキーはゲーム操作中に使います。投影を止めるには「投影を閉じる」。
読込み・閉じるの直接キーは初期未設定です。
「描画」で不透明度・境界線・表示レイヤー・比較表示・透過表示を調整します。
レイヤー方向は下→上／上→下／西→東／東→西／北→南／南→北などを選択できます。

### 検証する

配置を選択 →「検証」→ **「検証 / 材料を更新」**。
選択した設計図の読込み待ち、走査中、完了などの状態が表示されます。
走査中は「取消」で停止できます。
完了後は不足・種類違い・状態違い・余分などの分類を選び、一覧の行をクリックして位置を強調表示。
期待するブロック／状態と実際のブロック／状態を比較します。
ブロック変更、画面開閉、分類切替だけでは再検証しません。必要な時に手動更新してください。
表示行数には上限があり、件数は走査結果全体の値です。

### 材料を確認する

「材料」→「材料一覧を更新」。通常の材料一覧と、選択した配置の検証結果を表示します。
選択配置の合計／設置済み／残り／所持数は手動更新時点の値です。
所持数の「取得不可」は0ではありません。
LHoloの「HUD」で設計図のファイル・レイヤー・進捗・誤り表示を選びます。
材料HUDを使う場合は「不足材料を表示」をON。細かい位置・倍率はPraxisの「HUD配置」で編集できます。

### 構造を書き出す・設置補助を使う

「構造を作成」でポイント1・2の座標、または「プレイヤーの座標を使用」を指定し、`.mcstructure`を書き出します。
クライアントで読み込んだ範囲だけが対象で、コンテナー内部やエンティティ情報に制限があります。

設置補助は「実験的機能」で説明を読んで有効化します。
手動設置・簡単設置・範囲設置は互いに排他的で、モードは接続中だけの状態です。
画面の右クリック・照準・範囲設置の説明に従って使い、OFFで停止します。
「手動設置: 制限しないブロック」はIDを登録し、その物をメインハンドに持った時の通常設置の例外です。
自動持ち替えや投影への連続設置を追加する設定ではありません。

## 設定を保存・戻す

Praxisの「保存設定」で「現在の設定を保存」、名前を付けて保存、保存済み設定の読込み／削除ができます。
画面の処理状態で保存完了や失敗を確認してください。名前付き設定の読込みは現在値を変更します。
削除ボタンは選択した保存設定を削除するため、戻したいものを選んだ状態で押さないでください。
LHoloは設定変更を自身の設定へ保存します。
フォントの変更は次回起動時に反映。日本語化候補は従来のフォント・atlas・配置・操作を保持しています。
