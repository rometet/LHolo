LHolo Glass R5 + Praxis ResourcePack ABI v4 テストリリース
Minecraft統合版 1.26.51.01 / LeviLamina Client 26.51.5 / Windows x64

この版はGlass R5のガラス描画修正を維持しながら、本物のlholo_resource_reload_v4連携機構を復活させたLHoloのプレリリースです。
2026年10月21日のPraxis R33との実機確認では、指定されたオフライン複製ワールドにおいて、Minecraft本来のグローバルリソース画面からOFFにした後も自分の姿が三人称で表示され、両Modが復帰したことを確認しました。

重要：リソパのON/OFFとMinecraftの更新処理を管理するのはPraxis R33です。LHoloはその更新に安全に参加する側であり、これ単体で独立してリソパを切り替える機能ではありません。
通常ワールド、マルチプレイ、サーバー必須パック、複雑なシェーダーやスクリプトは未検証・対象外です。
既知問題の設定保存Access is deniedと終了時フック解除警告は残っています。

導入前にMinecraftを完全終了し、既存LHolo.dllと対応PDB、設定をバックアップしてください。
ワールドや設定は上書きしないでください。問題時は古いDLLと対応PDBの組を復元し、ゲームを再起動してください。
