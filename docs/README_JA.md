# LHolo | 日本語ガイド

[トップページ](../README.md) · [English](README_EN.md) · [简体中文](README_ZH_CN.md) · [Releases](https://github.com/rometet/LHolo/releases)

LHolo は、Minecraft Bedrock（Windows）で設計図を表示できる LeviLamina Client 用 Mod です。`.mcstructure` と `.litematic` に対応しています。現在の公開プレリリースの対象は **Minecraft 1.26.60.05 / LeviLamina Client 26.60系** です。

## まず使ってみる

1. ワールドに入って **`Insert`** を押します。チャットで `LHolo` と入力しても開けます。
2. **「ファイル」** から `参照` を選び、設計図ファイルを読み込みます。
3. **「配置」** で操作する投影を選択し、座標やレイヤーを調整します。
4. **「変形」** で位置、回転、反転を調整します。
5. **「検証」** で未設置や不一致のブロックを確認し、**「材料」** で必要数を確認します。
6. 不要になったら、メニューから投影を閉じるか配置を削除します。配置を削除しても元ファイルは残ります。

## 初期ホットキー

| 操作 | キー |
| --- | --- |
| メニューを開閉 | `Insert` |
| 構造を左・右・前・後へ移動 | `Ctrl + 矢印キー` |
| 構造を上・下へ移動 | `Shift + ↑ / ↓` |
| 表示レイヤーを変更 | `Alt + ↑ / ↓` |
| 視線方向へ投影を移動 | `Alt + マウスホイール` |

キーは **「ホットキー」** で変更できます。保存済みの設定がある場合は、ゲーム内で表示されている割り当てを優先してください。

## 主な画面

| 画面 | 用途 |
| --- | --- |
| ファイル | 設計図の読み込みとファイル管理 |
| 配置・変形 | 投影の選択、位置・向き・反転 |
| 検証 | 不足・種類違い・状態違い・余分なブロックの確認 |
| 材料 | 必要数、設置済み数、不足数など |
| 描画 | 不透明度、境界線、レイヤー、比較表示 |
| HUD | 進捗と材料の画面表示 |
| ホットキー | キーの変更、競合の確認 |
| インターフェース | 言語や UI 設定 |
| 実験的機能 | 手動設置、Easy Place、範囲設置、材料取得など |

**旧設定からの移行:** このフォークでは初期言語が日本語、初期メニューキーが `Insert` です。以前に自分で指定した言語やキーは維持される場合があります。必要ならメニューから変更・初期化してください。

## サイレント材料取得（ja.12 以降）

**「実験的機能」** のサイレント材料取得を ON にし、読み込んだ設計図に不足材料がある状態でチェストを **`Alt + 右クリック`** すると、必要な物を取得する処理を試みます。新規設定では OFF です。OFF にすると通常のチェスト操作に戻ります。

サーバー側のアドオンは不要ですが、すべての収納やサーバーでの動作を保証するものではありません。初回は失っても困らないアイテムで試してください。

## 注意事項

- Vibrant Visuals（鮮やかなビジュアル）は投影描画と競合する場合があり、OFF を推奨します。
- 投影自体はクライアント側のみですが、設置支援によるブロック設置は実際のワールドを変更します。
- 実験的な操作はサーバー規約を確認し、許可された場所でのみ使用してください。
- Minecraft 1.26.51 向けの旧ビルド（ja.x 系）は 26.60 では動作しません。対象の Minecraft バージョンに合うビルドを選んでください。

より詳しい配置・検証・材料・HUD の使い方は [Praxis / LHolo 操作ガイド](OPERATION_GUIDE_JA.md) を参照してください。
