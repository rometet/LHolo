# LHolo 日本語版

[简体中文](../README.md) | [English](README_EN.md)

Minecraft Bedrock 版向けのクライアント側構造投影 Mod です。`.mcstructure` と Java 版 Litematica の `.litematic` を読み込めます。

このフォークは Minecraft Bedrock 1.26.51 系 / LeviLamina 26.51.0 を対象に、日本語を初期言語として追加し、メニューを Praxis Client 風の中央パネルUIに調整しています。

## メニューを開く

- 初期キー: `Insert`
- 同じ `Insert` キーでもう一度閉じられます
- チャットに `LHolo` と入力しても開けます
- キーを変更する場合: `ホットキー` → `投影メニューを開く`
- 初期値に戻す場合: `ホットキー` → `すべてのホットキーを初期化`

以前の初期設定（簡体中文・`Alt + M`）は初回起動時に日本語・`Insert` へ移行します。自分で変更した言語やキー割り当ては保持されます。確実に `Insert` に戻したい場合は、ホットキーページで初期化してください。

## 投影ファイルの使い方

1. Minecraft のワールドへ入ります。
2. `Insert` で LHolo メニューを開きます。
3. 左側の `投影` を選びます。
4. `参照` から `.mcstructure` または `.litematic` を選びます。
5. `読み込む` を押します。
6. `変形` ページで位置、回転、ミラーを調整します。
7. 不要になったら `投影を閉じる` を押します。

## 初期ホットキー

| 操作 | キー |
|---|---|
| メニューを開閉 | `Insert` |
| 構造を左・右・前・後へ移動 | `Ctrl + 矢印キー` |
| 構造を上・下へ移動 | `Shift + ↑ / ↓` |
| 表示レイヤーを上・下へ変更 | `Alt + ↑ / ↓` |
| 視線方向へ構造を移動 | `Alt + マウスホイール` |

`Alt + マウスホイール` はホットキーページで無効化できます。投影の読み込み・終了キーは初期状態では未設定です。

## 主な画面

- `投影`: 構造ファイルの読み込み、材料一覧、前回の投影復元
- `構造を作成`: 2点を選択して `.mcstructure` を書き出す
- `変形`: 移動、回転、ミラー、表示レイヤー
- `描画`: 透明度、境界線、透過表示
- `HUD`: 進捗や不足材料の表示
- `ホットキー`: キー割り当て
- `インターフェース`: 言語とUI倍率
- `実験的機能`: 手動設置・簡単設置・範囲設置

実験的な設置支援はサーバーの規約やアンチチートに抵触する可能性があります。自分のワールド、または明示的に許可されたサーバーだけで使ってください。

## 表示上の注意

Vibrant Visuals（鮮やかなビジュアル）は、投影表示と競合する場合があります。LHoloの使用中は無効化を推奨します。
