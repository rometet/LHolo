# 検証画面の使い方

1. 設計図を投影し、配置一覧で検証する配置を選びます。
2. 検証画面の「検証開始」を押します。1回の有限走査で停止します。進行中は「停止」で取消できます。
3. 完了後、分類名を押すとブロックの組み合わせ一覧を開閉できます。「全て」は正常・未読込の集計も表示し、「エラーのみ」はエラーの4分類を表示します。
4. 分類選択と検索で絞り込みます。検索は設計図・実際のブロック名とstateを対象にし、英字の大小を区別しません。空白区切りの語はすべて一致する組み合わせを表示します。
5. 一覧の行を選ぶと、その組み合わせの最寄り座標をワールド内で強調表示します。詳細には期待・実際のstateと、保持された近くの座標を表示します。座標を選んで強調する位置を変更できます。
6. 「強調表示を解除」で選択を解除します。「リセット」は検証結果と選択を破棄します。投影・配置・ファイルは変更しません。

| 分類 | 色 | 意味 |
|---|---|---|
| 未設置 | 赤 | 設計図にあるブロックがありません |
| 違うブロック | 橙 | 設計図と異なる種類のブロックです |
| 状態違い | 黄 | ブロックの種類は同じですがstateが異なります |
| 余分 | 青 | 設計図の空気にブロックがあります。余分検出が有効な場合のみ数えます |
| 正常 | 緑 | 既存の検証規則で一致しています。合計のみ保持します |
| 未読込・判定保留 | 灰 | 読み込まれていない等の理由で判定できません。合計のみ保持します |

分類名の件数は全走査の集計です。表と詳細の件数は保持された結果の件数です。既存の保持上限は未設置512件、状態違い512件、種類違いと余分を合わせて512件、計1536件です。上限に達した場合は画面に説明が出ます。同じ分類・設計図のブロック/state・実際のブロック/stateを1行にまとめます。

座標は検証開始時の距離順で、括弧内がその距離です。「次の最寄りミス」は検索条件に関係なく、現在の分類内で保持結果を順に選びます。長いブロック名とstateは行のツールチップと詳細で確認できます。

幅が狭い画面では詳細が一覧の下に移ります。ページをスクロールして一覧・詳細へ移動できます。一覧と座標は個別にスクロールできます。検索の入力中はキーボードがその入力欄にフォーカスし、Escで解除できます。

ブロック変更、画面の開閉、分類・検索の変更、リセットだけでは検証を自動再開しません。再投影・配置や世代の変更では古い結果と選択を無効化し、新しい結果の表示時に古い検索文字列も消去します。確認するには再度「検証開始」を押してください。

一時停止・再開、正常ブロックの組み合わせと座標一覧、独立した互換分類、ネイティブのアイテム画像は追加していません。既存の状態機械・結果モデルにない機能のボタンは表示していません。座標と既存の強調表示を使用し、テレポートやサーバーコマンドは送信しません。
